# MintWord (薄荷词汇)

> [简体中文](../README.md) · [English](./README-en.md) · [한국어](./README-ko.md)

**MintWord** は、**SM-2 間隔反復アルゴリズム** をベースにしたクロスプラットフォームの語彙学習デスクトップアプリです。フロントエンドは React + TypeScript + Vite、バックエンドは Rust (Tauri v2)、データベースは SQLite を使用しています。

## 機能

- **間隔反復** — SM-2 アルゴリズムによる最適な復習スケジュール
- **内蔵単語帳** — 中国語試験向け 8 種の単語帳（CET-4、CET-6、大学院入試、GRE、TOEFL、IELTS、高考、中考）
- **カスタム単語帳** — 自作の単語帳を作成し、手動または一括で単語を追加
- **CSV インポート** — CSV ファイルから語彙をインポート
- **音声読み上げ** — Windows / macOS システム TTS + 設定可能な AI TTS（OpenAI 互換 API）
- **学習統計** — 復習履歴、ヒートマップ、学習進捗の追跡
- **習得マーク** — 習得したカードにマークを付け、復習から自動スキップ
- **ディクテーションモード** — 学習中にランダムでディクテーションを出題、単語の発音を聞いてスペルを入力
- **AI 出題** — 単語帳から自動で選択問題を生成、難易度・問題数・選択肢数を設定可能
- **AI 読解問題** — 文章をインポートし、AI で読解問題を生成
- **AI プロバイダ管理** — カスタム AI プロバイダ（OpenAI 互換インターフェース）の追加、モデルとパラメータの設定
- **ライブラリ** — 学習用文章の管理、TXT インポートまたは手動貼り付けに対応
- **クイックプレビュー** — 学習終了後に今回の単語を素早く復習
- **ノート機能** — 学習中にカードに個人的なメモを追加
- **テーマカラー** — 4 種類のテーマ（ミント、オーシャン、ウォーム、ラベンダー）+ ダークモード
- **多言語対応** — 簡体字中国語、繁体字中国語、英語、日本語、韓国語のインターフェース
- **ショートカットキー** — 学習中にキーボードで素早く操作

## クイックスタート

### 環境要件

- [Node.js](https://nodejs.org/) (v18+)
- [Rust](https://www.rust-lang.org/) (1.77.2+)
- [Tauri v2 システム依存関係](https://v2.tauri.app/start/prerequisites/)

### 開発モード

```bash
# フロントエンド依存関係のインストール
npm install

# 開発モード起動（Vite + Rust バックエンドを同時起動）
npx tauri dev
```

### ビルド

```bash
npx tauri build
```

### フロントエンドのみ

```bash
npm run dev      # Vite 開発サーバー（デフォルト localhost:5173）
npm run build    # 型チェック + フロントエンドビルド
npm run lint     # ESLint チェック
```
